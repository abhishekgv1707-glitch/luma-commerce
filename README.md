# Luma Commerce

A polished responsive e-commerce landing page built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev` and open `http://localhost:3000`.

For a production check, run `npm run build`.

## Highlights

- Responsive sticky navigation and mobile drawer
- Animated editorial hero, category cards, product grid, sale timer, testimonial carousel, and service proof points
- Interactive cart count and newsletter email validation
- Semantic landmarks, image alt text, keyboard-accessible controls, and visible focus states
